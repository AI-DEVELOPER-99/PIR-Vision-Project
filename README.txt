1. Project Summary:
    a. For this project we have created a jupyter notebook that has 9 sections.
    b. The 9 sections are (Features Overview, EDA, Preprocessing & Feature Engineering,
        Define & Train Model, Testing the model, Definition of evaluate model).
    c. The description for each step is provided in the notebook.

2. Required Libraries:
    a. The required libraries are given in requirements.txt file.
    b. To install the libraries first create virtual environment: python3 -m venv env
    c. Activate the virtual environment using: source env/bin/activate
    d. Install the libraries using: pip3 install -r requirements.txt

3. Instructions to execute the code:
    a. Follow all the steps in point 2
    b. For running evaluate model method: First run the cell-2, cell-6.1 and cell-8 
        and then run the cell-9 using evaluate_model(datafile_location, checkpoint)
    c. You can also run all the cells sequentially to check the output.
